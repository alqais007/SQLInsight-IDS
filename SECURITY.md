# Security Policy

## Overview

SQLInsight-IDS is a cybersecurity research project focused on detecting SQL Injection attacks using machine learning techniques.

Security issues related to the project are taken seriously.

---

## Reporting Security Issues

If you discover a security vulnerability, please report it responsibly instead of publicly disclosing it immediately.

Please include:

- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Suggested mitigation if available.

---

## Scope

Security reports may include:

- Detection engine weaknesses.
- Incorrect SQL Injection classification.
- Model-related security concerns.
- Vulnerabilities in demonstration environments.

---

## Responsible Disclosure

Please allow time for investigation and remediation before publicly sharing security findings.

---

## Security Considerations

Users should ensure:

- Sensitive information is not included in datasets.
- Testing is performed only on authorized environments.
- The project is not used for unauthorized security testing.

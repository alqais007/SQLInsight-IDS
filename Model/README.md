# Machine Learning Model

## Overview

This directory contains the machine learning model developed for SQLInsight-IDS.

The model is responsible for analyzing SQL queries and identifying potential SQL Injection attacks.

---

## Classification

The model performs binary classification:

- Benign SQL Query
- Malicious SQL Injection Query

---

## Model Evaluation

The model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score

---

## Performance Results

| Metric | Score |
|---|---|
| Accuracy | 99.08% |
| Precision | 99.03% |
| Recall | 98.47% |
| F1-Score | 98.75% |

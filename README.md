# SQLInsight-IDS

## Overview

SQLInsight-IDS is a Machine Learning-based Intrusion Detection System (IDS) designed to detect SQL Injection (SQLi) attacks in web applications.

The project combines machine learning techniques with cybersecurity principles to identify malicious SQL queries while minimizing false positives. A vulnerable WordPress environment was used as a proof of concept to evaluate the effectiveness of the detection model.

---

## Project Objectives

- Detect SQL Injection attacks using Machine Learning.
- Improve detection accuracy compared to traditional signature-based methods.
- Demonstrate real-world attack detection using a vulnerable web application.
- Evaluate the model using standard machine learning performance metrics.
